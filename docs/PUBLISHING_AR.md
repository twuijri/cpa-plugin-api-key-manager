# نشر بلقن في المتجر

المصدر الموجود في البروكسي ثابت؛ إضافة بلقن جديد لا تحتاج إنشاء مصدر جديد.

1. أعط الإضافة معرّفًا فريدًا مطابقًا لمعرّفها داخل ABI، مثل `gemini-desktop`، وإصدارًا جديدًا.
2. ضع المصدر ودليل الاستخدام والترخيص تحت `plugins/<plugin-id>/`. لا تنقل كود مفتاح القديم دون ترحيل مستقل لأدواته وروابطه.
3. ابنِ المكتبة للمنصة المطلوبة. حزمة ZIP تحتوي ملف `.so` واحدًا بالاسم الذي يتوقعه المضيف. اختبر المكتبة والمحادثات عند انطباقها.
4. ضع حزمة الإصدار تحت `downloads/<plugin-id>/<version>/` وأضف بصمتها وحجمها الحقيقيين. لا تستبدل ملف إصدار منشور؛ استخدم إصدارًا جديدًا.
5. أضف أو حدّث سجل الإضافة وحده في `registry.json`. حافظ على سجلات الإضافات الأخرى. المستودع يستخدم `schema_version: 2` وخطة تثبيت `direct` مع `goos` و`goarch` و`url` و`sha256` و`size`.
6. حدّث جدول README ودليل الإضافة، وراجع الأرشيف والمصدر للتأكد من عدم وجود جلسات أو مفاتيح أو ملفات `.private` أو `.env`.
7. انشر الكود والحزمة والفهرس في تغيير واحد، وتحقق من إمكانية تنزيل الرابط وتطابق SHA-256.
8. افتح Plugin Store في البروكسي واضغط Refresh، ثم Install أو Update. اختبر بعد التثبيت قبل إعلان نجاح النشر على السيرفر.

رابط الحزمة المباشر يكون مثل:

```text
https://raw.githubusercontent.com/twuijri/cpa-plugin-api-key-manager/main/downloads/<plugin-id>/<version>/<archive>.zip
```

احتفظ بإصدارات التحميل القديمة حتى تبقى روابط الفهارس السابقة قابلة للاستخدام. لا تربط سجل إضافة بإصدار GitHub عام `latest` قد يخص إضافة أخرى في هذا المستودع.
