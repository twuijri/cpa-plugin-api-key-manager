# Model Playground — نسخة المتجر

واجهة عربية بسيطة لتجربة موديلات البروكسي، مشتقة من [hex-ci/cpa-plugin-model-playground](https://github.com/hex-ci/cpa-plugin-model-playground).

افتحها من قائمة Plugins بعد التثبيت، وأدخل مفتاح عميل للبروكسي، ثم حمّل النماذج واختر الموديل وأرسل رسالتك. لا تستخدم مفتاح الإدارة.

المفتاح والمحادثات في ذاكرة الصفحة فقط؛ تُمحى عند إعادة تحميلها. الرد نصي ويدعم البث. لا حفظ دائم ولا Markdown. راجع [التغييرات](LOCAL-CHANGES.md) و[إشعارات الطرف الثالث](THIRD_PARTY_NOTICES).

هذه نسخة معدلة مستقلة برقم 0.3.0-local.1، وليست إصدارًا صادرًا عن صاحب المشروع الأصلي.
